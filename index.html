1
What is an IF Statement?
● ~3 minutes

An IF statement lets an algorithm make a decision. It checks a condition — something that is either true or false — and runs different steps depending on the answer. This is called selection.

Structured English
IF score >= 50 THEN
    Output "Well done, you passed!"
ENDIF
What each part does
  • IF — starts the decision block
  • score >= 50 — the condition being tested
  • THEN — what to do if the condition is true
  • ENDIF — closes the IF block
Key point: The steps inside the IF block (between THEN and ENDIF) only run if the condition is true. If the condition is false, the algorithm skips those steps entirely.

2
IF … ELSE Statements
● ~4 minutes

Adding an ELSE branch means the algorithm always does something — one path if the condition is true, and a different path if the condition is false.

Structured English
IF temperature < 10 THEN
    Output "Wear a coat"
ELSE
    Output "No coat needed"
ENDIF
How it works:
Condition TRUE (temperature < 10):
Outputs "Wear a coat"
Condition FALSE (temperature ≥ 10):
Outputs "No coat needed"
Exactly one branch always runs — never both, never neither.
Common mistake: Forgetting ENDIF. Without it, the algorithm is incomplete — the computer does not know where the IF block ends.

In an IF…ELSE statement, both the IF branch and the ELSE branch can run at the same time.

The ELSE branch runs when the IF condition is true.

3
Comparison Operators
● ~4 minutes

A condition in an IF statement uses a comparison operator to compare two values. The result is always either true or false.

Operator Meaning Example (age = 16) Result
= Equal to age = 16 TRUE
<> Not equal to age <> 18 TRUE
< Less than age < 18 TRUE
> Greater than age > 16 FALSE
<= Less than or equal to age <= 16 TRUE
>= Greater than or equal to age >= 16 TRUE
Watch out: > means strictly greater than — it does not include equal to. If you want to include the boundary value (e.g. a score of exactly 50 counts as a pass), you must use >=.

4
Logical Operators: AND, OR, NOT
● ~4 minutes

Logical operators let you combine or change conditions inside an IF statement, so you can test more than one thing at once.

AND

Both conditions must be true for the overall condition to be true.

IF age >= 12
  AND age <= 17
THEN
  Output "Teen"
ENDIF
True only if age is 12, 13, 14, 15, 16, or 17.
OR

At least one condition must be true for the overall condition to be true.

IF day = "Sat"
  OR day = "Sun"
THEN
  Output "Weekend"
ENDIF
True if it is Saturday or Sunday (or both).
NOT

Reverses the result of a condition — true becomes false, false becomes true.

IF NOT(loggedIn)
THEN
  Output "Please log in"
ENDIF
True only when loggedIn is false.
Quick reminder: AND is stricter — both must be true. OR is more flexible — either one being true is enough. NOT flips a single condition.

a) "Stay inside." — because isRaining is False, so NOT makes it True and the ELSE runs

✓ Summary — what you should now know
IF statement: runs a block of steps only when the condition is true. Must end with ENDIF.
IF…ELSE: provides two paths — one when the condition is true, one when it is false. Exactly one path always runs.
Operators: = <> < > <= >= — always compare two values and produce true or false.
AND: both conditions must be true. OR: at least one must be true. NOT: reverses a condition.
> vs >=: use >= when the boundary value should be included (e.g. pass is 50 or above).
Common mistake: forgetting ENDIF, or using AND when OR is needed (or vice versa).
